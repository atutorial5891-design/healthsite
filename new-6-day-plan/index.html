New 6-day plan — one muscle group per day

Every exercise for a muscle is on the same day (all shoulders on Wednesday, all core on Tuesday), arranged around the Tue · Thu · Sat runs. The original plan is still in the Exercise Library.

The Muscle focus list at the top ranks 24 specific muscles (forearms first), grouped upper body, lower body and core. Each has its own Videos list, showing NA until a good video is added. Below it, the nine functional groups hold the full exercise menu.

You don't need to isolate every muscle. Train these nine functional groups, with extra attention to running muscles and joints. Required = in your current weekly plan. Good to have = proven swaps and progressions for when equipment is busy or you want variety.

Difficulty is rated for a returning lifter at 45: Easy stable, low-skill, safe to start · Medium needs balance or technique · Hard high skill or load — add only after 8–12 weeks of consistent training. Stop any movement that causes knee pain.

New 6-day plan

Tap a day to show only that session's cards below

One muscle group, one day: every exercise for a muscle sits on the same day (all shoulder work is Wednesday, all core is Tuesday, and so on), so each muscle gets a full week to recover. Mon · Wed · Fri = gym strength days: legs, then push (chest, shoulders, triceps), then pull (back, biceps, forearms). Tue · Thu · Sat = run first, then a short home-friendly session that never loads the legs heavily: core, lower legs, hip stability. Sun = rest or an easy walk. Heavy legs sit on Monday so they've recovered by the weekend run — keep Tuesday's run easy, the day after legs. Friday has no leg work before Saturday's run. Don't skip the run-day session — it's the only day core, calves and side hips are trained. If fatigue builds, drop it to 1 set per exercise instead, and stop every run-day set 2–3 reps short of failure. Never add heavy legs to a run day. Missed a gym day? Do it on Sunday, or add its first 3 exercises to the next gym day — otherwise those muscles go a full two weeks untrained.

Gym days: warm up 5 min (easy bike or brisk walk), then 3–4 lighter ramp-up sets of the first exercise (age 45+). On Wednesday, also do 1 light set of Face Pull before pressing to wake up the shoulders. Getting stronger: when you hit the top of the rep range on every set with 2 reps still in the tank, add a little weight next week. Every 4–6 weeks: take an easy week — about 40% fewer sets and ~10% lighter weights. After every run: 5 min easy walk before the light session. Wednesday is the longest day: do Lateral Raise and Reverse Fly back-to-back, and the two triceps moves back-to-back, to save time. OR options: every exercise in the library has a day. Each main exercise is done every week; an OR line under it is a same-muscle swap for variety, a busy machine or a home day — do the main one OR the swap, never both.
