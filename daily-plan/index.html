Weekly 3-day split

Train Monday, Wednesday, and Friday. Rest Tue / Thu / Sat / Sun. Tap the red play button next to any exercise to watch form demos in a closable pop-up.

Before each session (~8 min): 3–5 min light cardio → dynamic hip/shoulder circles → 2 ramp-up sets on your first compound lift.

After lifting: Post-workout whey + steps/cardio per your main dashboard targets. Optional 5–10 min belly/side finisher: Fat Loss Videos. Need more days? See the 5-day split on the dashboard.

⏱ Is this achievable? — time math

Rough estimate = sets × (~45 s work + listed rest) + ~8 min warm-up. Age 45+ · leave 1–3 reps in reserve — you do not need every accessory every week.

Day Sets Full session Busy-day target
Mon Push ~31 ~80–90 min ~60–70 min (core path)
Wed Legs ~46 ~100–115 min ⚠ long ~70–85 min (core path)
Fri Pull ~31 ~75–85 min ~60–70 min (core path)

Weekly load: 3 lifts ≈ 3.5–4.5 h if you run the full lists · ~3–3.5 h on the busy-day paths below — realistic for a fat-loss + muscle-preserve block.

Time-savers (use freely): Superset isolation pairs (e.g. Lateral + Front Raise, Curl + Hammer, Adduction + Abduction). Rest 60 s on machines when joints feel good. Skip “optional” rows entirely.

Busy-day core path — keep compounds, trim accessories:

  • Mon: Bench · Incline DB · Shoulder Press or Arnold (not both) · Lateral Raise · Rope Pushdown · Overhead Ext. Skip Front Raise + one forearm move if clocking out.
  • Wed: Pick one squat pattern (Leg Press or Goblet or Back Squat) · RDL · Ham Curl · Bulgarian or Lunges · Hip Thrust · Standing Calf · Cable Crunch · Plank. Alternate hip add/abd weekly; drop Seated Calf + Dead Bug when short.
  • Fri: Lat Pulldown (skip wide variant) · Cable Row · Chest-Supported Row · Face Pull · Curl · Farmer’s Carry. Skip Straight-Arm / Rear Delt / Shrug / Hammer if under 60 min.

Verdict: Achievable if Wed is treated as a menu (core path most weeks) and Mon/Fri stay near the busy-day list. Full lists are fine on high-energy weeks or when you can stay ~90+ min.
