Good to Know

Key principles, rules, and curated resources from your health program (v3.4)

🎯 Training Philosophy

  • ✓Train for consistency, not exhaustion
  • ✓Technique before adding weight
  • ✓Stop each set with 1–3 reps in reserve (RIR)
  • ✓Log every workout (exercise · weight · reps · RIR)
  • ✓~80% nutrition adherence is success
  • ✓A missed session is a data point, not a failure

🧓 Age 45+ Must-Dos

  • ⚠Warm-up ramp: 3–4 sets (not 2–3)
  • ⚠Tue/Fri mobility is non-negotiable
  • ⚠Favor 12–15 reps if joint feels cranky
  • ⚠Add rest day if joint (not muscle) sore 48h later
  • ⚠Deload every 4–6 weeks (not 6–8)

📈 Progression Rules

Load Increase

When ALL sets hit top of rep range with good form: +2.5–5% upper body, +5–10% lower body

Deload Timing

Every 4–6 weeks (at age 45). Reduce sets ~40% AND drop load ~10%.

Strength Plateau Rule

Lift fails to add a rep for 3 consecutive sessions (~3 weeks) → pull deload forward 1–2 weeks.
